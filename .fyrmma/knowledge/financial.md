# Métricas Financeiras SaaS

---

# MRR

Monthly Recurring Revenue.

Receita recorrente mensal.

Exemplo:

100 clientes pagando R$ 97/mês:

```
100 x R$ 97

= R$ 9.700 MRR
```

---

# ARR

Annual Recurring Revenue.

Receita recorrente anual.

Fórmula:

```
MRR x 12
```

Exemplo:

```
R$ 9.700 x 12

= R$ 116.400 ARR
```

---

# Churn

Clientes perdidos.

Exemplo:

100 clientes

5 cancelaram

Churn:

5%

---

# LTV

Lifetime Value.

Valor total esperado de um cliente.

Considerar:

- ticket médio
- tempo de permanência
- margem

---

# CAC

Customer Acquisition Cost.

Custo para adquirir um cliente.

Exemplo:

Investimento marketing:

R$ 1.000

Clientes novos:

10

CAC:

R$ 100

---

# Regra SaaS

Idealmente:

```
LTV > CAC
```

O cliente deve gerar mais valor do que custa adquirir.
